# Optional GPU acceleration.
#
# CTranslate2 needs the CUDA 12 maths libraries at runtime. Installing the CUDA
# toolkit system-wide works, but these pip packages are self-contained and the
# worker adds their directories to the DLL search path itself (Windows will not
# look inside site-packages on its own).
#
#   .venv/Scripts/python.exe -m pip install -r requirements-cuda.txt
#
# Roughly 600 MB. Worth it: `turbo` is far slower than real time on CPU and
# comfortably faster than real time on a supported GPU.
#
# Requires an NVIDIA driver new enough for CUDA 12. Cards older than Volta
# (compute capability < 7.0, e.g. GTX 10xx) cannot do float16 — the worker
# detects this and selects float32 automatically.

nvidia-cublas-cu12
nvidia-cudnn-cu12
